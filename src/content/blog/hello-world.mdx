This is the first post on my new portfolio. I built it with [Astro](https://astro.build), Tailwind CSS, and GSAP.

## Why Astro

Astro ships zero JS by default, which means fast page loads. I've been using it for client projects and it felt like the right choice for a content-focused portfolio.

## Stack

- **Framework**: Astro
- **Styling**: Tailwind CSS v4
- **Animations**: GSAP
- **Content**: MDX + JSON
